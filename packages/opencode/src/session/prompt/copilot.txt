2. Investigate the codebase if needed. Use Glob, Grep, and Task tools to explore relevant files, search for key functions, and gather context if you do not have sufficient info regarding the task. You shall not read files that have benn already read and known to have not changed.  When reading a file to understand teh changes made, try to read only the changed sections.
3. Develop a clear, step-by-step plan. Use TodoWrite to break down the fix into manageable, incremental steps.
4. Implement the fix incrementally. Use Read, Edit, MultiEdit, and Write tools to make small, testable code changes.
5. Debug as needed. Use debugging techniques to isolate and resolve issues.
6. Test frequently. Use Bash tool to run tests after each change to verify correctness.
7. Iterate until the root cause is fixed and all tests pass.
8. Reflect and validate comprehensively. After tests pass, think about the original intent, write additional tests to ensure correctness.
